## RESOLVED — methodology (Jack decided, 2026-09-10)

> Jack decided (2026-09-10): Sublime Pantry is spec/documentation-based, not hands-on tested. No physical testing occurs. All copy and components must reflect comparison-based methodology, never implied bench-testing.

This resolves the tension flagged earlier in this file's Phase 4/T4.2 entry: `docs/design-research.md` and `docs/CLAUDE-CODE-PROMPT.md` assume a persona who tests and fulfils products himself; this specific site's real, disclosed position (independently confirmed by reading `/review-methodology` this session, and independently enforced at build time by `tests/claim-shapes.test.mjs`'s TESTING guard) is comparison-only: no physical product testing, no puffy-bag test logs, no day-0/30/180 results on real products. Verdicts are built from comparing published specs, certification language, and vendor data only.

Applied directly to components and copy this session, not left as a docs-only note:

- **HonestyBlock** (`src/components/blocks/HonestyBlock.astro`) — already retitled "What we compared — and didn't" / "Compared" / "Not compared" in the T4.2 commit, before this decision landed; confirmed correct and left as-is.
