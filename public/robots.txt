# This site is written to be read and cited by machines as well as people, so
# the answer-engine and AI-training crawlers below are named explicitly and

# removes any question about intent, and gives us one line to change per agent
# if that intent ever changes.

# page: it says nothing a reader searching for an answer wants, and indexing it
# strands people in the middle of a form they never filled in. (The Batch Log's
# export is a client-side download, not a route, so there is nothing to
# disallow for it.)
